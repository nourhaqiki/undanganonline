# Animation PRD audit

1. **HIGH — R-26 / R-35:** The invitation UI does not implement the requested interaction contract. The music control is positioned at the top-right, navigation may exceed five items and has no scroll-spy state, copying is Alpine-specific rather than `.btn-copy`-based, and the cover handover uses a 700ms default transition instead of the specified 900ms sequence.
2. **HIGH — R-19 / R-39:** No `motion.css` or dedicated Vite motion modules exist. The current reveal uses Tailwind's default `ease-out`, lacks the requested variants and stagger, does not unobserve revealed elements, and has no reduced-motion implementation for continuous ambient motion.
3. **HIGH — R-19 / R-40:** The templates have no butterfly system or layered botanical ornaments, so the required three-layer butterfly structure, non-synchronous flight paths, stem-anchored multi-layer floral sway, selective layer promotion, and pointer-event isolation are absent.
4. **HIGH — R-24 / R-31:** No event category is passed as the required normalized DOM value, and nothing conditionally omits romantic ornament DOM for non-wedding events. Current persisted category values are Indonesian (`pernikahan`, `tunangan`, `bisnis`, `lainnya`), so the category normalization must be explicit before the strict `wedding` / `engagement` gate can work safely.
5. **MEDIUM — R-31:** Shared invitation behavior and UI are embedded in `themes/partials/engine.blade.php`; the required invitation components and isolated ES modules are absent. Keeping this concern separated is necessary to apply the PRD consistently to every theme without duplicating the system.

## Follow-up

Findings 1–5 resolved. The floating player and bottom navigation are the only two frosted surfaces, kept above invitation content to make persistent mobile controls legible. The existing theme palettes and typography remain unchanged. Floral detail is limited to the romantic event categories, while the butterfly layer is a non-interactive decorative overlay. Motion is reserved for the cover handover, scroll hierarchy, and ambient romance cues.
